# Что работает и чего не хватает

Дата прогона: 2026-10-21. Ядро: 124 теста, `cargo test --bin pcagent`.

## Что работает

1. **Чекпоинт перед шагом.** В снимок входят тронутые файлы (включая факт «файла не было»), активное окно, граф, трасса, критерии и полная копия SQLite. Манифест пишется последним. Откат либо возвращает файлы, память и фокус вместе, либо при ошибке на любом шаге кладёт прежнее состояние обратно. Битый снимок живое дерево не трогает.

2. **Разбор сбоя и остаток плана.** Причина берётся из последней строки трассы или лога (`ошибка:`, отказ проверки), а не из текста «готово». Проваленный узел и пропущенные потомки снова становятся ожидающими, уже сделанное не переигрывается. Новый план проходит Z3 до исполнения.

3. **JEV через OpenRouter.** `POST https://openrouter.ai/api/alpha/decisions`, модель `typesafe/jev-1.13`. `noul` — да/нет, `choice` — выбор узла среди готовых. Ключ `OPENROUTER_API_KEY` в Debug и в текст ошибки не попадает. Нет ключа или сеть молчит — задача идёт по локальной статистике. Одинаковый запрос берётся из кэша, канонический JSON не зависит от порядка полей.

4. **Порядок шагов.** MiniZinc вызывается отдельным процессом. Если бинаря нет, пробуется OR-Tools через `python`. Оба отсутствуют — остаётся порядок планировщика, это не выдаётся за оптимум. `PCAGENT_OPTIMIZER=qubo` подключает отжиг QUBO. Интерфейс `QuboMinimizer` потом можно заменить железом, постановка задачи та же. Любой порядок перед исполнением ещё раз проверяет Z3.

5. **Критерии до старта.** Из текста задачи достаются цитаты и сравнения. Пустая строка и «ок» критерием не становятся. Закрытие требует, чтобы каждый критерий был виден на экране, и чтобы Z3 принял решение по графу. Иначе статус `incomplete`.

6. **Watchdog.** Пульс пишется на каждом шаге. Просрочка — зависание, процесс поднимает последний целый снимок. Следующий запуск видит `running` и снимок и продолжает ту же задачу. Без снимка задача помечается прерванной, а не «доделанной».

7. **Запуск.** По-прежнему `./run`.

## Чего не хватает

- MiniZinc и OR-Tools на этой машине не стоят, поэтому внешний решатель здесь не дал числа. Код их вызывает и, не найдя, честно оставляет порядок планировщика.
- Квантового процессора нет. Есть только отжиг за тем же интерфейсом `QuboMinimizer`.
- Живой задержки OpenRouter нет: без ключа клиент сеть не трогает.
- Снимок не отменяет клик, который уже ушёл в чужое окно. Возвращаются файлы, память, граф и фокус записанного окна.
- Зависший системный вызов сторож не убивает: флаг рестарта читается, когда вызов вернулся. У LLM есть свой таймаут. Жёсткая смерть процесса подхватывается следующим запуском со снимка.
- Сборка и эти тесты гонялись на Linux. Windows-джоб CI по-прежнему должен собрать Z3 сам.
