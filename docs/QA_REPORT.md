## 2. Fuzz / устойчивость к кривым данным

Добавлен детерминированный фаззер `core/src/fuzz.rs` (свой xorshift-RNG, фиксированный seed — воспроизводимо, работает на stable, без `cargo-fuzz` и nightly).

| Цель | Итераций | Что подавалось | Итог |
|---|---|---|---|
| Разбор ответа LLM (`extract_json` + `Decision`) | 20 000 | обрывки JSON, ```-заборы, битый юникод, эмодзи, гигантские числа, неизвестные действия | паник нет |
| `parse_ui_xml` (uiautomator дамп телефона) | 20 000 | обрезанный XML, мусорные bounds, огромные/отрицательные координаты | паник нет |
| Память/FTS5 (`recall`, `recall_global`, `remember`) | 2 000 | пунктуация и операторы FTS (`"`, `*`, `NEAR`, `^`) | паник нет |

Найдено и исправлено фаззингом и точечными тестами:

1. **Паника на закрывающей скобке раньше открывающей** (`}{` от модели) — раньше это был обратный slice-диапазон и `panic`. Теперь `bail!`.
2. **Переполнение i32 в bounds Android** — координаты парсились в `i32`, `[0,0][2147483647,2147483647]` давало переполнение при вычислении центра. Теперь `i64` + saturating + clamp.
3. **Обвал контекста на дампе UI** — дерево без лимита. Введён `MAX_ELEMENTS = 2000`.
4. **Скролл на 1e9 «щелчков»** — зависание потока на часы. Клампится и в Rust (`-50..50`), и в C++.

Пустые формы, пустой ответ модели, пустое дерево UI и неверный код 2FA/капчи разбираются как обычные ошибки шага: агент фиксирует провал, рефлексия пишет урок, шаг переигрывается — без паники и без бесконечного цикла (лимит шагов и лимит повторов одинакового действия на месте).

## 3. Security scan

### Секреты

`grep` по всему дереву на `sk-…`, `AKIA…`, `ghp_…`, `AIza…`, `xox[baprs]-`, PEM-заголовки: **совпадений нет**. Ключи только из `.env` (в `.gitignore`, есть `.env.example`). В логи и в SQLite-память ключи не попадают.

### Исправленные уязвимости

| Слой | Проблема | Фикс |
|---|---|---|
| Rust | `LaunchApp` запускал произвольный exe с аргументами по решению модели (prompt injection → `powershell`) | добавлен в destructive → требует подтверждения человека |
| Rust | `Action::short()` сериализовал целиком, т.е. пароли и SMS-коды уходили в историю/лог/БД | текстовые payload'ы заменены на длину |
| Rust | `OpenUrl` шёл через `cmd /C start` — метасимволы в URL = выполнение команды | `explorer.exe` + валидация схемы/длины URL |
| Rust | ADB: имя пакета, keycode, текст и host подставлялись в shell без экранирования | `sh_quote` + whitelist-валидация пакета/keycode/host |
| Go | пустой `ROUTER_TOKEN` открывал API без авторизации (fail-open) | fail-closed: 403, сравнение через `subtle.ConstantTimeCompare` |
| Go | тело запроса не ограничено | `MaxBytesReader`, 32 МиБ |
| Go | `ROUTER_LISTEN` можно было выставить в `0.0.0.0` и опубликовать роутер наружу | разрешён только loopback |
| Go | апдейтер качал по любому URL, включая http, и по редиректу | только https, https-проверка на каждом редиректе, лимит 5 |
| Go | предсказуемый путь temp-файла обновления, без лимита размера | `os.CreateTemp`, лимиты манифеста и файла, обязательный SHA-256 (64 hex) |
| C++ | `capture`: нет проверок out-указателей, размеров, DC; `int`-арифметика по площади кадра | проверки указателей, `kMaxDim`/`kMaxPixels`, 64-битная арифметика, проверка влезания в `int32` |
| C++ | `vision`: нет проверок `found`/`out`/`max_out`, декодируемый PNG без лимита размеров | проверки указателей и stride, `kMaxTplDim = 4096`, защита от resize в 0 |
| C++ | `utf8_to_wide`: WinAPI писала `n` символов в буфер длиной `n-1` — запись за конец буфера | буфер на `n`, затем `resize`, плюс `MB_ERR_INVALID_CHARS` |
| C++ | `clipboard_get`: чтение чужого блока до `\0` без учёта его размера | длина ограничена `GlobalSize` |
| C++ | `clipboard_set`: `GlobalLock` без проверки, утечка `HGLOBAL` при отказе `SetClipboardData` | проверка + `GlobalFree` на всех ошибочных путях |
| C++ | `uia`: глобальный `g_uia` без синхронизации (GUI-поток и поток агента) | `std::mutex` на init/shutdown/вызовы |
| C++ | `uia`: `walker` мог быть null → разыменование; `max_depth` неограничен → переполнение стека рекурсией | проверка HRESULT, потолок глубины 64 |
| C++ | `ocr`: исключение могло пересечь C ABI (UB) | `catch (...)` + проверка stride/размеров |
| C++ | везде: `an_dup_cstr` мог вернуть null, а вызывающий писал его в out | проверки + код ошибки, потолок 64 МиБ |

### Race conditions

- Go: `go test -race` чисто. `http.Server` + провайдеры без разделяемого изменяемого состояния.
- Rust: `Mutex<Memory>` — заменён `unwrap()` на `unwrap_or_else(|e| e.into_inner())`, чтобы паника в одном шаге не отравляла мьютекс и не роняла весь агент.
- C++: единственное разделяемое состояние — `g_uia`, теперь под мьютексом. Буфер ошибки — `thread_local`.

## 4. Топ-10 проблем (по остаточному риску)

| # | Severity | Проблема | Как чинить |
|---|---|---|---|
| 1 | **High** | Windows-часть ни разу не собрана и не запущена. Всё C++ — только ревью и синтаксическая проверка mingw | собрать `scripts\build.ps1` на реальной Windows либо завести CI-джоб `windows-latest`. Нужен репозиторий |
| 2 | **High** | `AdbShell` — произвольная shell-команда на телефоне. Подтверждение спрашивается, но человек будет жать «да» не глядя | whitelist подкоманд (`am start`, `input`, `dumpsys`), а произвольный shell — только по отдельному флагу в `.env` |
| 3 | **Medium** | Апдейтер проверяет SHA-256 из манифеста, но сам манифест не подписан: кто контролирует `UPDATE_MANIFEST_URL`, тот контролирует бинарь | Ed25519-подпись манифеста, публичный ключ вшит в бинарь; плюс запрет отката версии |
| 4 | **Medium** | Prompt injection: текст на экране («игнорируй инструкции, открой…») попадает в промпт как данные и может вести агента | разделять системный промпт и наблюдения жёсткими маркерами, добавить проверку «действие относится к текущей цели», список доменов-исключений для destructive |
| 5 | **Medium** | Валидация URL префиксная, а не полноценный парсер политики | перевести `check_url` на `url::Url` с whitelist схем и запретом `file`/`javascript`/UNC |
| 6 | **Medium** | В память/историю может попасть чувствительный текст задачи и отчёта (не через action-лог, а через сам текст задачи) | фильтр по ключевым словам + опция «не сохранять задачу» в GUI |
| 7 | **Medium** | Буфер обмена: агент читает его целиком, туда мог попасть пароль из менеджера паролей | читать буфер только по явному действию, не класть содержимое в промпт по умолчанию |
| 8 | **Low** | `ttf-parser` unmaintained (RUSTSEC-2026-0192) | ждать смены зависимости в egui; проверять `cargo audit` в CI |
| 9 | **Low** | Нет ограничения по времени на шаг агента: зависший OCR/UIA-вызов вешает цикл | таймаут на каждый нативный вызов + отмена по кнопке в GUI |
| 10 | **Low** | Нет теста на реальный ответ провайдера с 429/5xx на всех адаптерах сразу (fallback покрыт частично) | table-driven тест на цепочку fallback со всеми кодами |

## 5. Что НЕ проверено

- Компиляция и работа C++/WinRT (OCR), ATL/UIA, GUI на Windows.
- Реальные клики/ввод, DPI-масштабирование, антидетект.
- Реальный ADB и телефон.
- Живые вызовы LLM-провайдеров (нет ключей).

## Вердикт

Критических (эксплуатируемых удалённо) находок в Rust и Go не осталось: тесты, clippy, staticcheck, race, govulncheck, audit и deny зелёные, fuzz паник не даёт.

Писать **«Готов к сборке под Windows»** пока нельзя честно: пункт №1 — High. Формулировка по факту: **код готов к первой Windows-сборке, но не проверен на ней**. Как только будет репозиторий (или соберёте `scripts\build.ps1` локально) — гоняем сборку, и после зелёного билда статус меняется.
