# web/ — интерфейсы и визуалы

Три самостоятельные страницы. Сервер не нужен, но `file://` не даёт браузеру
загружать ES-модули, поэтому проще поднять статику:

```
cd web && python3 -m http.server 8088
```

| Страница | Что это |
| --- | --- |
| `house/` | 3D-штаб «Management House»: шесть отделов, ходьба от первого лица, клик по терминалу открывает показатели отдела |
| `zishel/` | лендинг Zishel Phallo: линейка, условия, заявка на прайс уходит в WhatsApp |
| `fx/` | FX-визуал продукта (`ZISHEL_ROSE_GLAM`): вращение, три палитры, кадр PNG и ролик WEBM для рекламы |

## house/ — управление

`WASD` — идти, `Shift` — бежать, мышь — обзор, ЛКМ по терминалу — карточка отдела,
`Esc` — выйти из обзора. Сквозь стены и терминалы пройти нельзя.

Показатели отделов лежат в массиве `DEPARTMENTS` в начале скрипта — там же
меняются названия, цвета и строки карточек. Если рядом с `house/index.html`
положить `leads.json` (экспорт радара: `pcagent --radar radar.json --out leads.json`),
отдел продаж покажет реальное число лидов и HOT-лидов вместо прочерков.

## zishel/ — заявки

Номер продавца задаётся одной строкой в скрипте:

```js
const SELLER_WHATSAPP = '77000000000';
```

Форма ничего не отправляет на сервер: она проверяет номер (форматы `+7…`, `8…`,
10 цифр), требует согласие на связь и открывает WhatsApp с готовым текстом
заявки. Так лид приходит от самого клиента — с согласием и без риска блокировки
номера, в отличие от холодной рассылки.

## fx/ — материал для рекламы

`КАДР PNG` сохраняет текущий кадр, `ЗАПИСЬ 8 СЕК` — ролик `webm`
(`MediaRecorder`, если браузер его поддерживает). Палитра переключает
`ROSE → CYAN → GOLD`, вращение можно остановить для статичного кадра.

## Офлайн

Three.js подключается с `unpkg.com`. Чтобы страницы работали без интернета,
скачайте `three.module.js` и папку `examples/jsm/` рядом со страницей и
поправьте пути в `importmap`.
